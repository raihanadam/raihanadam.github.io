Tentang

Statistika dan informatika dalam satu layanan.

Berlatar belakang pendidikan Statistika Bisnis dan Teknik Informatika dari Institut Teknologi Sepuluh Nopember (ITS), saat ini tengah menempuh program doktor Ilmu Komputer.

Perpaduan dua disiplin ini memungkinkan penanganan proyek data secara menyeluruh: mulai dari perancangan metodologi, pengolahan dan analisis data, hingga penyajian hasil dalam bentuk laporan penelitian, dashboard interaktif, maupun website.

Berpengalaman di lingkungan korporasi melalui program magang di PT PLN Nusantara Power Services, serta di sektor pemerintahan desa melalui pengembangan dashboard data untuk perangkat desa di Kabupaten Magetan.
