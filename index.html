Tentang saya

Halo, saya Raihan. Latar belakang saya ada di dua bidang yang saling melengkapi: statistika terapan (S.Tr.Stat.) dan ilmu komputer (M.Kom). Saat ini saya sedang menempuh program doktor Informatika di Institut Teknologi Sepuluh Nopember (ITS).

Kombinasi ini membuat saya bisa menangani pekerjaan data dari hulu ke hilir: merancang analisis yang benar secara metodologi, mengolahnya dengan tools yang tepat, lalu menyajikannya dalam bentuk yang mudah dipahami, baik berupa laporan penelitian, dashboard, maupun website.

Pengalaman saya meliputi magang di PT PLN Nusantara Power Services dan membangun dashboard data untuk perangkat desa di Kabupaten Magetan.
